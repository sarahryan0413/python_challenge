# 🐍 Python Financial & Election Data Analysis
## Description:
This challenge has me diving into Python to automate two real-world data analysis tasks:
- 📊 PyBank – Analyzing financial records to figure out total months, net profit/loss, monthly changes, and the biggest gains/losses over time. No more manual calculations—Python’s got this!
- 🗳️ PyPoll – Helping a small town modernize their election process by counting votes, calculating percentages, and determining the winner without touching a single spreadsheet.

The datasets are huge (on purpose), so this is all about making Python do the heavy lifting. This challenge is gonna flex my skills in loops, file handling, and data manipulation—plus, I get to see how powerful scripting is for big data. 🚀
